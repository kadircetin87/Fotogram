# Fotogram 📷

Fotogram – kişisel bir fotoğraf albümü projesi. 12 fotoğrafı grid olarak gösterir ve tam ekran (fullscreen) dialog görüntüleyici ile fotoğrafları büyütmenizi sağlar.

## Özellikler

- 12 fotoğraflık responsive galeri (grid) düzeni
- Fotoğrafa tıklayınca tam ekran `<dialog>` görüntüleyici
- Sadece **HTML, CSS ve vanilla JavaScript** ile geliştirildi
- Erişilebilirlik için `aria` etiketleri
